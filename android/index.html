Installa Studemo
Come si installa, in mezzo minuto
  1. Tocca Installa Studemo: parte il file (185 MB, meglio col wi-fi).
  2. Apri il file appena scaricato.
  3. Se il telefono chiede il permesso, tocca Consenti e poi Installa.

Il file resta fermo? Tocca ⋮ in alto a destra e scegli Apri in Chrome.

Sto preparando il file Lascia la tua email sulla pagina di Studemo: ti scrivo io appena l'app per Android è pronta da installare.

Google Play arriva dopo: il negozio chiede prima un periodo di prova con dodici persone. Questo file è la stessa app, con gli aggiornamenti dentro.
